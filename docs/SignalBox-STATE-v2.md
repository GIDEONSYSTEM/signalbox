## 0. Что это

Студия подкастов. Утилита `SignalBox` (Фаза 2; до 2026-08-04 называлась `CamCollector`) — мониторинг/управление камерами Sony в OBS по Wi-Fi (Sony Camera Remote SDK, PC Remote / PTP-IP).
Камеры: **2× Sony ZV-E1**, **1× ZV-E10 II** (в SDK — `ZV-E10M2`), возможно **FX3**.
Один C++ процесс: подключается ко всем камерам, опрашивает ~1/сек, поднимает HTTP-сервер на **:8787**, отдаёт пульт (HTML) и live view. OBS цепляет пульт как **Custom Browser Dock**. Обкатано на живой ZV-E1.

> **🐞 ЗОМБИ-ПРОЦЕССЫ — ПОЧИНЕНО (2026-08-04).** Симптом (репорт юзера): нажал «Выключить», а в диспетчере задач висят процессы; при следующем запуске «камеры уже подгружены, будто и не выключался». Факт: **4 живых процесса SignalBox** одновременно, порт слушал только последний. Причина: shutdown делает `poller.join()` / `discoverer.join()`, а поток discovery сидит внутри **блокирующего SDK `Connect()` к несвязанной камере** — join не возвращается никогда. Порт при этом уже освобождён (`server.stop()`), поэтому следующий запуск стартовал нормально и показывал панель ЖИВОГО старого процесса → иллюзия «не выключался». Мои первые тесты проходили лишь потому, что попадали между попытками подключения.
> **Фикс:** `startShutdownWatchdog(8)` — запускается первым делом в shutdown; через 8с, если процесс ещё жив, пишет в лог, при `g_restart` вызывает `relaunchSelf()`, снимает значок и делает `TerminateProcess(GetCurrentProcess(), 0)`. Плюс relaunch вынесен в идемпотентный `relaunchSelf()` (атомик `g_relaunchDone`), чтобы сторож и обычный путь не породили два процесса. Стресс-тест (выключение через 2/5/8/11с): все 4 цикла чистый выход за 0.8–3.7с, зомби 0.

> ℹ️ **Имя приложения ≠ имя папки (2026-08-04).** Приложение переименовано `CamCollector` → **`SignalBox`** (exe, UI, консоль, ярлыки, `project()`/`add_executable()` в CMake). **Папка проекта осознанно осталась `CamCollector\`** — чтобы не инвалидировать CMake-кэш (`CMAKE_HOME_DIRECTORY`) и не пересоздавать `build\`. Поэтому во всех путях ниже каталог по-прежнему `CamCollector\`, а бинарь — `SignalBox.exe`. Если когда-нибудь переименовывать и папку: удалить `build\`, сконфигурировать заново (VS17 2022, x64) и пересобрать.

## 2. HTTP API (порт 8787, `INADDR_ANY` → доступен с телефона/LAN)

- `GET /status.json` → `{ "server":"http://<lan-ip>:8787/", "cameras":[ {id,model,ip,online,rec,battery,acPower,cardMinutes,writing,iso,isoEff,aperture{cur,opts},shutter{cur,opts},wb{cur,opts},wbKelvin} ] }`
  - **`server`** — LAN-адрес сервера (из `localIPv4()`, кэшируется на запуск), чтобы пульт знал свой адрес даже открытый на `127.0.0.1`. Хардкода нет: на каждом ПК считается свой (в HTML только фолбэк `127.0.0.1`).
  - **Как выбирается адрес (переделано 2026-08-04):** `GetAdaptersAddresses` + линк `iphlpapi`; пропускаются выключенные и loopback; вес = `ipScore` −60 за виртуальный IfType (tunnel 131 / PPP 23 / propVirtual 53) +25 за настоящий шлюз (не 0.0.0.0). Все кандидаты и веса — в лог строками `[net]`. ⚠️ **Не пытаться определять адрес через маршрут в интернет** (UDP connect к 8.8.8.8): при VPN проба уходит в туннель — проверено, выбирался `172.18.0.1` (xray_tun) вместо `192.168.0.176` (Ethernet). Сейчас: VPN вес 20, Ethernet 125 → выбирается верный.
- `POST /cmd` — `{cam:N|"all", action:"rec"|"iso"|"aperture"|"shutter"|"wb"|"wbkelvin", value:...}`.
- `POST /restart` — чистый перезапуск (сам себя перезапускает с `--restarted`).
- `POST /shutdown` — чистое выключение: тот же путь, что раньше давал `q`+Enter (сбрасывает `g_running`, камеры отключаются корректно). Ответ успевает уйти: цикл `HttpServer::run` перечитывает флаг только после того, как ответил и закрыл сокет.
- `GET /liveview/<n>.jpg` — последний JPEG + заголовок `X-Cam-Frames` (рамки JSON). Помечает камеру активной.
- `GET /` → пульт; `GET /<file>` — статика из www\.

## 3. Как реализованы фичи (C++)

- **Discovery/pairing:** авто-обнаружение PTP-IP, подключение с повтором. Каждую камеру раз связать на самой камере (Меню → Сеть → Функции удалённой съёмки → Связывание, подтвердить имя ПК `WIN-T1I0U6MAIDA`). Старт печатает сводку «подключено / ждут связывания».
- **Статус:** `GetSelectDeviceProperties` ~1/сек. acPower по `CrBatteryLevel_USBPowerSupply`/`CrPowerSource_DC/PoE`; карта — `MediaSLOT1_RemainingTime`.
- **rec:** `SendCommand(CrCommandId_MovieRecord, Down→Up)`, идемпотентно. `toggleRecAll()` — тумблер (направление по `cachedRecording()`/атомик `m_recCached`).
- **iso:** маска `& 0x00FFFFFF`, AUTO=`0xFFFFFF`.
- **Кельвины:** чтение/запись через **`CrDeviceProperty_Colortemp`=0x0115** (UInt16, значение = кельвины). НЕ через `WhiteBalancePresetColorTemperature`(0x2A5) — ZV-E1 его не отдаёт.
- **aperture/shutter:** `FNumber`/`ShutterSpeed` (cur+opts). Мануальная оптика → `aperture.opts` пуст.
- **MIDI (winmm):** все MIDI-входы; триггер **CC канал 1 (0xB0), контроллер #17**, на нажатие (`d2!=0`), дебаунс 80мс → тумблер записи на всех. Клавиатурный хоткей убран.
- **Live view (по запросу, ~7 fps):** поток `liveViewWorker` тянет кадры только для камер с открытым превью (эндпоинт ставит `g_lvActiveMs`, активна ~1.5с). Кэш `g_lvCache`. `grabLiveView`: `GetLiveViewImageInfo`→`GetLiveViewImage` + `GetLiveViewProperties`.
  - **Рамки: нужно включить `CrDeviceProperty_OSDImageMode=CrOSDImageMode_On`** (UInt8, один раз, `m_osdEnabled`), иначе рамки `sz=0`. **HDMI остаётся чистым.**
  - `FocusFrameInfo`(ft=1,0x121,зона АФ), `FaceFrameInfo`(ft=4,0x581,глаз/лицо), `TrackingFrameInfo`(ft=5,0x193). Координаты нормализованные (cx=xNum/xDen…). Захват = `type`: `AF_TargetFace=2`/`TargetAF=2` (не `state`). JSON рамки `{cx,cy,w,h,st,ty,k}`, k=focus/face/track. Заголовок `X-Cam-Frames` (+`Access-Control-Expose-Headers`).
- ⚠️ **ГРАБЛЯ:** `snprintf("%.4f")` на RU-локали печатает ЗАПЯТУЮ → битый JSON. Числа форматировать локале-независимо (`fx4()`).

## 4. Пульт `cam-control-panel.html` — текущий вид

Полностью управляется данными: одна карточка на онлайн-камеру (`online!==false`), выключенных нет. Пусто → «Нет подключённых камер» / «Сборщик не запущен».
**`LV_BASE`** = тот же origin если открыт по http (док/телефон), иначе `http://127.0.0.1:8787` (для file://). Все запросы (status/cmd/liveview/restart) идут на `LV_BASE` → **пульт работает и с телефона** (раньше был жёсткий `127.0.0.1` — чинили).

- **Шапка (одна строка):** `[МОДЕЛЬ] · [аккумулятор+молния] · [SD-иконка+минуты] · … · [STBY/REC справа]`. IP убран. Модель — `friendlyModel` (ZV-E10M2→«ZV-E10 II»), `nowrap`. Аккумулятор: без %, тёмно-зелёная заливка `--bat-ok #33b466`, отступ 2px, клемма по центру; молния горит при `acPower`. Время карты «2ч22м» (без пробела).
- **В шапке справа кнопки «Перезапустить»** (id `rstBtn`, 2 клика — «Точно?» жёлтая, 2.5с → `POST /restart`) **и «Выключить»** (id `offBtn`, класс `.rst.off`, 2 клика — «Точно?» красная → `POST /shutdown`, затем оверлей `#offScreen` «SignalBox выключен» и флаг `shuttingDown` глушит опрос, чтобы не мигало «нет связи»). Рядом бейдж live/демо.
- **Блок «Доступ к панели» (под мастер-кнопками):** строка с адресом (`#shareUrl`, из `data.server`, иначе `location.origin`) — **клик копирует в буфер** (`navigator.clipboard` с фолбэком `execCommand` для http/несекьюрных контекстов) и показывает **toast** «Адрес скопирован» (`#toast`). Рядом **QR** (`#shareQr`) с этим адресом.
- **QR — свой генератор** (офлайн, без внешних сервисов): `qrGen(text)`→матрица, `qrToSvg(text)`→SVG. Byte mode, ECC **M**, версии 1..6, полный RS/маска(выбор по штрафу)/формат-инфо. Отрисовка SVG (`shape-rendering:crispEdges`, quiet-зона 4).
- **Управление:** REC (одно нажатие, тумблер), ISO (select + степперы), ряд Диафрагма/Выдержка/ББ-K, мастер «Запись·все»/«Стоп·все».
- **Live Preview:** выпадающий раздел, окно 16:9 без полос (кадр задаёт высоту), тянется только когда открыт. Два тумблера рамок: «Рамка глаза»(face/track) и «Зона АФ»(focus). Захват — зелёный (`ty===2`), иначе белый. Кнопка **⟳ поворот** 0/90/180/270° (для вертикальной съёмки, `lvApplyRotation`).

## 6. Грабли (must-know)

- Выход только кнопкой **«Выключить»** на панели (раньше — `q`+Enter). Убийство процесса → камера отклоняет новое подключение (`0x820A CrError_Connect_FailRejected`, чистится долго). Имя ПК для связывания: `WIN-T1I0U6MAIDA`.
- RU-локаль + `snprintf("%f")` → запятая → битый JSON (см. §3).
- Рамки фокуса требуют `OSDImageMode=On`.
- CAM-нумерация — по порядку обнаружения (две ZV-E1 могут меняться местами между запусками).
- Фронтенд-правки без пересборки; C++ — с пересборкой (закрыть exe).
