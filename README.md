# SignalBox

Remote Control — мониторинг и управление камерами Sony по Wi-Fi для студий подкастов.

Одна программа для Windows: находит камеры в сети, опрашивает их, поднимает локальный
веб-сервер и отдаёт панель управления, которую можно открыть в браузере, на телефоне
или прицепить в OBS как Custom Browser Dock.

## Что умеет

- автоматически находит камеры Sony (PC Remote / PTP-IP), а если сеть режет автопоиск —
  подключается по IP и запоминает камеры на будущее;
- запись, ISO, диафрагма, выдержка, баланс белого — по одной камере или на всю группу;
- группы («съёмочные залы»): общая запись, сворачивание, перетаскивание камер между залами;
- Live Preview с рамками автофокуса и лиц;
- управление записью с MIDI-контроллера;
- доступ с телефона по адресу и QR-коду;
- обновление через GitHub Releases.

Работает офлайн: шрифты, генератор QR и всё остальное лежит локально, в интернет
программа ходит только за обновлениями.

## Сборка

Нужен Visual Studio 2022 Build Tools (toolset v143) и Sony Camera Remote SDK.
Проект ожидает, что рядом лежит распакованный SDK с примером `RemoteCli` —
оттуда берутся заголовки (`RemoteCli/app/CRSDK`) и библиотека (`RemoteCli/external/crsdk`).

```
cmake --build build --config Release
```

Сам SDK в репозиторий не входит: он принадлежит Sony и скачивается с их сайта.

## Структура

| Путь | Что это |
|---|---|
| `src/` | исходники C++ |
| `res/` | иконка приложения |
| `build/Release/www/` | панель управления (HTML/CSS/JS), шрифты, библиотека QR |
| `docs/` | описание состояния проекта для передачи между сессиями |
